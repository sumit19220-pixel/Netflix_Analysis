#  Netflix Content Analysis Dashboard | Power BI

##  Project Overview

This project presents an interactive Power BI dashboard that analyses Netflix content using IMDb ratings, audience votes, runtime, release trends, content type, and age certifications. The goal is to uncover viewing trends, evaluate content performance, and provide insights into Netflix's content library through interactive visualisations.

---

##  Project Objectives

- Analyse the distribution of Movies and TV Shows.
- Explore content release trends over the years.
- Evaluate IMDb ratings and audience engagement.
- Compare content across different age certifications.
- Identify the highest-rated and most popular titles.
- Build an interactive dashboard for data-driven decision-making.

## Key Insights

- Movies represent a larger share of the catalogue than TV Shows.
- Content production has increased significantly over recent years.
- Certain age certifications dominate the platform's catalogue. Adults Movies are highly rated than other age categories.
- Average Runtime for movies has decreased over the years while for shows average runtime has increased over years
- Inception is the highly rated movie, while stranger things is the highly rated show.
